# Run with ordinary services

Declare an ordinary service under `services.<name>` with `compose` and representative `service`, then add an explicit requisite from main or a reachable ordinary consumer. `dependency` waits for health; `prerequisite` waits for a successful job; `requirement` includes without ordering. An endpoint-less module is valid and runnable if it has `service`. `builder service up dev --full` and `prod` use the active graph; isolated dev starts only the ordinary nodes that `dev.on-inframode-isolated` reaches. To run a local helper such as a dev database without leaving isolated mode, follow the [3.1 to 3.2 migration guide](../migration/v3.1-to-v3.2.md#add-a-helper-to-isolated-dev). The [Compose contract](../reference/dependency-compose-contract.md) explains member ownership.
