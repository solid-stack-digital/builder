# Replace local mocks with mesh services

Suppose frontend main has a `source.backend` dependency on its local mock. In `mesh.json.services.frontend.extends.main`, set `requisites.source.backend` to `false`, add `requisites.backend: "dependency"`, and set `env.BACKEND_URL` to `${backend.source.main.endpoints.http.network_url}`. This explicitly changes inclusion, readiness and URL. Repeat for every nested ordinary consumer that used the mock. No provider map, automatic endpoint matching or readiness inheritance remains. See the [migration walkthrough](../migration/v2.2-to-v3.0.md#mesh-two-source-roots-and-explicit-replacement).
