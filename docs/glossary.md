# V3 glossary

**Main** is the application service in each build. **Tester** is a separate Compose module whose selected runner determines E2E status. An **ordinary service** is an atomic Compose module; its **representative** is the container used for health or completion. A **source** is an independently runnable build imported by a mesh. **Extends** explicitly changes an existing source service in a mesh. A **stage** selects an overlay; a workflow phase may use a different Dockerfile target.

A **requisite** is an explicit directed edge. **Requirement** includes a target without ordering; **dependency** waits for health; **prerequisite** waits for successful completion. **Closure** or **reachability** is the set of nodes found by following requisites from a consumer. **Publication capability** is `publicPort`; **effective publication** makes a reachable endpoint accessible from the host. **Isolated** runs a source main without ordinary nodes; **integrated** runs the effective closure. V2 “provider substitution” is historical terminology; use explicit source rewrites.
