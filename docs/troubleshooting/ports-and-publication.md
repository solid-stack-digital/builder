# Port and publication errors

A mesh endpoint with `publicPort` remains private until an effective source `publish` selector chooses it. Use `<local>.endpoints.<endpoint>` and ensure the node is reachable by requisites. `publish` cannot create reachability. A stage array replaces the prior list; repeat selectors you still need. Fixed host-port collisions fail; `AUTO` proposes an available port and may reallocate if a cached port is busy. If a public reference fails, inspect capability, selection and closure separately. See [publication](../concepts/publication-and-ports.md).
