# Add ordinary services and requisites

Under `build.json.services`, declare an ordinary module such as `db` with `compose`, optional endpoints and a representative `service`. Declaration alone starts nothing. Add `"db": "dependency"` to `services.main.requisites` to include it and wait for representative health in integrated runs. A job without endpoints still needs `service`; use `"migration": "prerequisite"` for completion before main. An ordinary module's `env` applies to every member container and does not inherit main dotenv. See the [ordinary Compose contract](../reference/dependency-compose-contract.md) and [build reference](../reference/build-json.md).
