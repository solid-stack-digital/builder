# Two-phase tests

`builder service up test` first runs isolated unit work with the `test` main target and `.env.test`. After strict teardown, service E2E uses a production main, full graph, `.env.e2e`, and the selected source runner. `builder mesh up test` runs each **base** source's complete standalone test sequentially, cleans each, then runs a fresh integrated global E2E composition. Stage-only mesh sources join the global stage but not Phase 1. The global runner has its own Compose and `.env.e2e-tester`; source runners do not leak into Phase 2. See [stage matrix](../reference/stage-matrix.md).
